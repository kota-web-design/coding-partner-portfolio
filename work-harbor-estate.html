HARBOR ESTATE｜不動産会社ホームページ コーディング実績

※画像クリックで実際のデモサイトをご覧いただけます

概要

福岡県内の主要エリアに対応する架空の不動産会社「HARBOR ESTATE」を想定した、複数ページ構成のホームページ実装です。
地域密着感と暮らし提案型の世界観を保ちながら、物件検索・詳細ページ・お問い合わせ導線まで実案件に近い構成で制作しました。

担当範囲

  • 担当範囲HTML / CSS / JavaScript コーディング
  • ページ構成TOP・物件一覧・売買詳細・賃貸詳細・会社概要・お問い合わせなど14ページ
  • 対応内容レスポンシブ対応 / UI実装 / 画像ギャラリー / フォームUI / 公開前チェック

実装のポイント

  • 買う・借りるの条件切り替えを含む物件検索UIを実装
  • 売買物件詳細と賃貸物件詳細で、CTAや物件情報の見せ方を出し分け
  • 物件写真のスライダー、サムネイル、モーダル拡大表示をJavaScriptで実装
  • お問い合わせフォーム、FAQアコーディオン、ハンバーガーメニューなど基本UIを実装
  • PC/SPで余白・文字量・ボタンサイズが自然に見えるようレスポンシブ調整

制作会社様向けに意識したこと

見た目の再現だけでなく、後から修正しやすいclass設計、共通パーツの使い回し、画像差し替えのしやすさを意識して実装しています。

また、スマホ表示では余白・改行・CTAの押しやすさを重点的に調整し、リンク切れ、画像パス、alt属性、フォームUIなども公開前に確認しています。

使用技術

  • HTML（セマンティックなページ構成）
  • CSS（レスポンシブ対応・共通パーツ設計）
  • JavaScript（スライダー・アコーディオン・検索UI・モーダルギャラリー）
