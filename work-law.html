福岡みらい法律事務所｜
法律事務所ホームページ コーディング実績

※画像クリックで実際のデモサイトをご覧いただけます

概要

福岡市西新を拠点とする架空の法律事務所「福岡みらい法律事務所」を想定した、14ページ構成のホームページ実装です。
専門性と相談しやすさの両方が伝わるデザインを保ちながら、取扱分野・弁護士紹介・費用・解決事例・お問い合わせまで実案件に近い構成で制作しました。

担当範囲

  • 担当範囲HTML / CSS / JavaScript コーディング
  • ページ構成TOP・取扱分野・弁護士紹介・解決事例・費用・事務所案内・6分野の詳細など14ページ
  • 対応内容レスポンシブ対応 / FAQ UI / フォームUI / 共通パーツ / 公開前チェック

実装のポイント

  • 全ページ共通のヘッダー・フッター・CTAを再利用しやすい構造で実装
  • 取扱分野から6つの詳細ページへ迷わず移動できる導線を実装
  • FAQアコーディオン、スマホメニュー、フォームバリデーションをJavaScriptで実装
  • 費用表はPCの表形式から、スマホでは読みやすいカード形式へ切り替え
  • PC/SPで画像比率、余白、改行、CTAサイズが自然に見えるよう調整

制作会社様向けに意識したこと

下層ページが増えても修正箇所を追いやすいよう、共通クラスとページ固有クラスを分けて実装しています。

また、弁護士名・電話番号・所在地・ナビ表記など、複数ページで表記がずれやすい情報を統一し、リンク切れ、画像パス、alt属性、h1、重複IDまで公開前に確認しています。

品質・アクセシビリティ確認

  • スマホメニューとFAQの開閉状態をARIA属性へ反映
  • キーボード操作時のフォーカス表示とEscキーでのメニュー閉鎖に対応
  • 各ページのh1、title、description、OGPを設定
  • デモフォームであることを明記し、実送信されない挙動へ調整
  • PC・スマホの主要画面で横スクロールと表示崩れを確認

使用技術

  • HTML（セマンティックなページ構成）
  • CSS（共通パーツ設計・レスポンシブ対応・スマホ用費用カード）
  • JavaScript（スマホメニュー・FAQ・フォーム制御）

デモサイトについて

本サイトは、架空の法律事務所を想定したポートフォリオ用デモサイトです。実在の人物・団体・案件とは関係ありません。
