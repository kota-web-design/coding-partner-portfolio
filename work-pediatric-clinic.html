小児科クリニックホームページ コーディング実績

※画像クリックで実際のデモサイトをご覧いただけます

概要

福岡市西区姪浜の小児科クリニックを想定した、7ページ構成のホームページ実装です。
やさしいデザインの世界観を保ちながら、診療案内・予防接種/乳幼児健診・初診案内・アクセス・お知らせまで、実案件に近い構成で制作しました。

担当範囲

  • 担当範囲HTML / CSS / JavaScript コーディング
  • ページ構成TOP・クリニック紹介・診療案内・予防接種/健診・初診案内・アクセス・お知らせの7ページ
  • 対応内容レスポンシブ対応 / 共通パーツ / 予約導線UI / デモモーダル / 公開前チェック

実装のポイント

  • 全ページ共通のヘッダー・フッター・SP固定CTAを再利用しやすい構造で実装
  • 「WEB予約」「初めての方へ」「予防接種・健診」へ迷わず進める導線を実装
  • 予約ボタンは実送信ではなく、ポートフォリオ用デモモーダルとしてJavaScriptで制御
  • お知らせ一覧はWordPress組み込みを想定し、投稿カード・カテゴリ・ページネーションの見た目を実装
  • PC/SPで文章の改行、カード幅、診療時間表、ページ内ナビが自然に見えるよう調整

制作会社様向けに意識したこと

デザインの再現だけでなく、下層ページが増えた場合にも修正しやすいよう、共通クラスとページ固有クラスを分けて実装しています。

また、医療系サイトとして誤解を招かないよう、実在の医療機関ではないこと、実際の診療・予約が行われないことを全体で明記しています。公開前チェックとして、リンク切れ、画像パス、alt属性、OGP、横スクロール、コンソールエラーも確認しました。

品質・アクセシビリティ確認

  • スマホメニューの開閉状態をaria-expandedへ反映
  • dialog要素を使った予約デモモーダルと背景クリックでの閉じる動作を実装
  • FV画像はPC/SPで切り替え、表示速度と見え方を調整
  • title、description、OGP、favicon、canonicalなど公開前に必要な基本情報を設定
  • PC・スマホの主要画面で横スクロールとテキストの読みづらい改行を確認

使用技術

  • HTML（セマンティックなページ構成）
  • CSS（共通パーツ設計・レスポンシブ対応・SP固定CTA）
  • JavaScript（スマホメニュー・予約デモモーダル・スクロールアニメーション）

デモサイトについて

本サイトは、架空の小児科クリニックを想定したポートフォリオ用デモサイトです。実在の医療機関ではなく、実際の診療・予約は行われません。
